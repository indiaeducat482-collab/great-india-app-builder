# Great India App Builder V2
WebToNative-style original dashboard and app creation flow.
Includes My Apps, App Builder, Services, App Details, Builds, Android/iOS/Both selection, feature selection, Supabase Auth/database integration and GitHub Actions build hook.

The workflow is a build hook. A real APK/AAB compiler still requires an Android/Capacitor project plus secure signing and artifact upload. Never put service_role or signing secrets in frontend files.
